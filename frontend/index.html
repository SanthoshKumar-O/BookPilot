Page 14 — Section 3.2: Parameter Update Equations

Optimization lies at the core of training deep statistical models. Given a loss function \(L(\theta)\), our primary goal is to find the parameter vector \(\theta^*\) that minimizes total prediction error over the dataset.

📌 Important Concept Score: 9.5
Gradient Descent is an iterative optimization algorithm used to find a local minimum of a differentiable function.
💡 In simple terms: Imagine standing on a foggy hill. To reach the bottom, you take small steps in the steepest downhill direction.

In standard batch gradient descent, parameters are updated continuously by moving in the direction opposite to the gradient of the loss function with respect to the parameters:

🧮 Formula
$$\theta_{t+1} = \theta_t - \eta \cdot \nabla_\theta L(\theta_t)$$
Where \(\eta > 0\) represents the learning rate (step size).

If the learning rate \(\eta\) is set too high, the algorithm may overshoot the minimum and diverge. Conversely, if \(\eta\) is set too small, convergence will be extremely slow.

💻 Python Snippet 
def gradient_descent_step(w, dw, lr=0.01):
    # Parameter update in opposite direction of gradient
    return w - (lr * dw)
